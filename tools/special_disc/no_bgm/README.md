# SP 战斗鉴赏「关闭 BGM」

外层「BGM 设置」的第四项关闭本场原生背景音乐，保留语音和音效。鉴赏用专用选曲值 `0x7E` 显示「无 BGM」。原版曲号 101 仍可供动画装载音效库。

- 选择静音后保留原来的左右队长设置。鉴赏组装战斗请求时解析当前队长的默认曲；原先选择「不自动设置」时使用右队长，队长缺失时使用原版回退曲 `0x38`。更换单位时保留静音，切回普通选项或手动选曲后恢复原生播放。
- 旧版保存的「不自动设置 + 101」在鉴赏从保存字段刷新显示时迁移为 `0x7E`。读卡和选曲处理都局限于鉴赏。原生同步、异步放歌入口保持原始指令。
- 在鉴赏请求上设置本场标志，五处音乐音量命令 `0xB0` 在标志有效时使用零音量。战后发起菜单曲请求前清除标志。

正式入口是 `writeback/build_full_text.py` 的 `apply_no_bgm`。简体测试盘可用 `python3 tools/build_editions.py --editions sp --single-language --candidate` 构建。程序头 70 从 `0x81FC00` 装载补丁，位于比例字体保留区之后、事件鉴赏区之前。

2026-11-06 旧版使用曲号 101 的历史录像和读数保存在 `docs/issue-assets/sp-no-bgm-20261106/`。

2026-11-22 的 ARMSX2 回归从简体候选盘冷启动。由旧盘在游戏内写出的鉴赏存档读回后，选曲值从 101 迁移为 126。左队长 53 号曲切到静音、保存并读回后，开战请求仍为 53；切回右队长可恢复 51 号。与日版同招式录像比较，普通与静音两组的德尔塔「吸血银十字」40 次、欧米伽「烈火爆裂蹴」43 次音效地址均逐项一致。两组完整战斗的音效地址、音量和语音触发也分别一致，返回鉴赏时 99 号曲的起播音量为 `0x9B`。
