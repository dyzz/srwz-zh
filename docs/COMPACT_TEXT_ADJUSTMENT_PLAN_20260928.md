## 确定的排版顺序

1. **先满足可读性约束。** 不改变字母大小写、数字值或名称身份；保留原段落及空白分隔。
2. **保护普通词与专名。** 复用已有剧情词库，补充本轮发现的“结束、拍摄、帮助、越狱”等词。
   保护可跨宽度标签；不允许出现“战斗结／束”，也不因追求齐行而拆开混合名称。
3. **尊重中文断行。** 句末、分句边界优先；括号、引号、逗号等遵守行首／行尾禁则。
   短介绍优先完整句界；长段落在这些约束内尽量让各行长度接近。
4. **按像素平衡。** 用字形宽度和推进距离测量；考虑末字右侧越界。段首缩进只减少第一行的可用宽度。
5. **最后检查全部预算。** 行宽、最多行数、固定槽字节、压缩容量、共享引用、滚动时序和页面返回后的字体状态分别检查。

英文／英数与数值表达式仍以至少 3 个字符为门槛，使用 `0E/0C`；中文标点保持原宽。
表达式中的 `.`、`:`、`/`、`-`、`+`、`±`、`%`、范围号、乘号及千位逗号纳入完整段；
Unicode `−`、希腊字母、中点、其他数学符号先检查码表和字形，不静默替换。
含 `÷` 的完整表达式暂不自动收窄。过长的闭合段必须显式选择词间分段或其他可读参数；不能截断字符。

## 甲儿截图的修正与运行发现

附件是把审定的 Dove 介绍放进甲儿面板的 RAM 测试，不是甲儿本人的译文。
原分行虽然两行宽度接近，却拆开了后半句：

```text
贝克的部下。与Dove
一起帮助贝克越狱。
```

当前规则选为：

```text
贝克的部下。
与Dove一起帮助贝克越狱。
```

![修正后的完整两行](../work/reviews/compact-inventory-20260928/runtime/character-explicit-body-start.png)

运行时发现：只有后半句带窄距标签、正文开头未设置恢复值时，第一行会被省略。
纯文本同样分行正常，开头补 `<width:16><space:16>` 后两行正常。
结合已分析的原生测宽函数会修改共享字体状态，这是本轮补正文起始恢复的依据；没有宣称已单步跟踪全部内部路径。

实现生成的最终正文及双字节编码与通过样本**完全一致**，含 NUL 为 54 字节。
比无起始恢复的标签载荷增加 4 字节。四个实验保留了结果：显式起始恢复通过；
仅缩进的变体第二行丢失；“与 Dove 一起”同行的替代分行通过；无标签对照通过。
失败截图保留为反例，不计入验收。

SP 第 3 话《迷途》的自然流程面板亦做了同页隔离对照：“战斗结束”不再拆词，最后一段按句意平衡；
两份载荷都为 410 字节／8 行。后续流程页另有返回／进入检查记录。
