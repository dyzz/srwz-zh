# 0.5.0 发布视频：文本提升、审阅站数据与详细致谢

取数日期：2026-11-08。写作与剪辑依据，供后续脚本改写使用。英文文字渲染仍在调整，不列为已经完成的改善；本文件讨论的文本提升是翻译、口吻、术语与阅读节奏。

## 一、把“文本变好了”拆成能展示的变化

1. **更准确地理解上下文**：分清否认、安慰、请求和命令；补足主语、对象与因果，不能只换几个好听的词。
2. **更自然的中文与人物口吻**：减少直译句式，结合搭档关系、敌我关系和场景选择措辞。战斗台词也需照顾条件和前后接话。
3. **跨页面与版本的一致性**：同一人物、机体、地点、技能在对白、战斗字幕、梗概、图鉴和说明中使用一致译名；不能把口头简称全部机械替换成正式全名。
4. **阅读节奏**：按句意调整换行、引号和对白段落。换行调整、翻译修改、英文字体渲染分开叙述。
5. **保留审阅历史**：吸收授权参考时保护已有社区意见，不用一批新文本直接覆盖之前的讨论结论。

计数口径：

- **16,828 是上述语料范围的小计，不是全项目总量**。不含菜单与名称映射表、图鉴的字段覆盖、图片文字、代码和 SP 新增内容。剧情按资源文本位置计数，不等于独立句子数，也不等于审阅站可见对白数；图鉴按共享译文条目去重，不按每个页面重复展示次数累加。
- “仅排版”机械忽略空白、实际／转义换行、全角空格与 width/height/space/color 显示标签后相同；“仅标点”是在此基础上去除 Unicode 标点后相同。其余归为“文字或其他字符变化”，可能包含用词、译名、数字、符号及未识别控制标记变化，**不能直接称为 12,234 处翻译错误修复**。标点类也可能伴随排版调整，文字类也可能伴随标点调整，三类互斥。
