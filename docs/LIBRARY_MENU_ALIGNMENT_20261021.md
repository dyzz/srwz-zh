# 资料库主菜单字号与居中（2026-10-21）

六项名称采用同一份 HarmonyOS Sans SC Regular 冻结纹理：机体图鉴、角色事典、术语事典、音乐选择、剧情流程、攻略问答。前五项从 26 号、末项从 24 号统一缩小到 22 号，并按实际字形边界校准水平中心和纵向行距。最后一项保留原有独立纹理框。

本篇契约为 `config/library/v0.2.0.json` 的 `library_menu_runtime_tim2`，快照为 `config/library/library-menu-runtime-render-snapshot.json`。目标是 `DATA/NISVDATA.BIN` 块 0 内的 TIM2；不写入外观相似的 JTIM 纹理。

SP 原生块 0 的同一纹理位于解压偏移 `863488`，不能套用本篇的记录编号或偏移。`tools/special_disc/writeback/library_menu.py` 用原始 TIM2 SHA-256 唯一定位 SP 记录，再从当前本篇冻结契约取得六项索引像素；只替换六个文字矩形，保留 SP 的其他像素、CLUT、TIM2 元数据、其他压缩块及原有槽大小。普通构建不重新栅格化。SP 的固定输入清单已包含使用的本篇日文 NISVDATA 与锁定字体，不依赖较早的本篇构建产物。

SP 全文本构建在 Q&A 文本写回之后应用菜单，独立最终 ISO 验证器重读六项纹理并核对共享契约与快照身份。菜单处理不替换 SP 专有的 Q&A 页面或其他文本。

验证包括：冻结构建与作者渲染结果一致，文字框无裁切，六个矩形外的索引不变；SP 压缩回读与重复应用一致；未翻译旧菜单及源纹理身份漂移被拒绝；其他 TIM2 图片的像素改动被保留。
