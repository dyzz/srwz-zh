# v0.3.0 正式版发布说明

v0.3.0 主要整合 v0.2.0 发布后的玩家反馈，补齐此前未完成的内容，并对剧情、
战斗、资料库和多处界面显示进行了集中校对与修正。

## 内容补全

- 补齐攻略 Q&A 正文、列表和相关提示；
- 完善教学关卡、剧情流程及多处低频菜单内容；
- 补齐特殊分支、集市事件、自动编队名称等此前遗漏的文本路径；
- 继续完善人物、机体、武器、技能和帮助说明等资料内容。

## 文本校对与润色

- 根据日文原文和实际剧情语境修正一批错译、漏译、称呼和语序问题；
- 统一人物名、机体名、组织名及常用专有名词；
- 修正多处剧情对白、战斗台词、胜败条件和动态提示；
- 处理发布后反馈中发现的断句、残留日文和不自然表达。

## 界面与显示完善

- 完善剧情流程、攻略 Q&A、音乐选择、资料库和搜索界面的中文显示；
- 修正剧情流程标题与概要排版，放宽正文换行并避免常用词被拆开；
- 修正搜索页标签居中、自动编队剩余小队数字间距及多处提示位置；
- 修复若干标题背景、透明区域、字形兼容和全角字符显示问题。

## 安装

本项目只分发 xdelta 补丁，不包含 ISO、存档或其他原版数据。请自行合法持有与
Redump Disc 4932 校验值一致的原版镜像，并保持文件名为
`Super Robot Taisen Z (Japan, Korea).iso`。

安装 xdelta3 后，在发布包目录执行：

```bash
xdelta3 -d \
  -s "Super Robot Taisen Z (Japan, Korea).iso" \
  "srwz-zh-v0.3.0.xdelta" \
  "srwz-zh-v0.3.0.iso"
```

请勿在旧汉化版或其他修改版镜像上重复打补丁，操作前请备份原版镜像和存档。
