# 《超级机器人大战 Z》三语合盘 v0.5.2

Original 初版、The Best 廉价版和 SP 特别盘各用一份 xdelta。请按手中日文原盘的版本选择补丁。

| 版本 | 日文原盘 |
| --- | --- |
| Original 初版 | SLPS-25887 / 1.04 |
| The Best 廉价版 | SLPS-73270 / 2.00 |
| SP 特别盘 | SLPS-25920 / 1.01 |

## 语言与画面

在标题菜单等待输入时按 SELECT 打开设置。语言项可用左右键选择简体中文、台湾繁体或香港繁体。按圆圈保存，重启游戏后使用所选语言。开机时按住 SELECT 可临时进入台湾繁体。

画面比例项可在 4:3 和 16:9 之间切换。语言和画面设置会保存在记忆卡。台湾文本采用「歐普」，香港文本采用「奧布」。

## 自 v0.5.1 以来的文本修订

校订了三语剧情对白和断行，统一人物名「王李」，同步更新港台译名、术语表、机体与武器名及攻略。第三轮繁体复查涉及 298 个文件，共修订台湾 902 串、香港 891 串，包括发射和发动的「發」、量词「隻」、武器名「複相光束炮」「低後座炮」，以及剧情里的儿化和应答语。台湾用「好咧」，香港用「好呀」。

## 战斗

三版均内置战斗动画快进。演出中按住方块键（□）可跳到下一个阶段。

初版、The Best 和 SP 特别盘都内置了金手指。在整备主菜单或战场上自由移动光标时按 SELECT 打开菜单。用上下键选择项目，用左右键调整，按 ○ 确认，按 × 取消。七项设置包括战斗收益、资金／蓝石、机师 PP、精神指令、武器消耗、改造上限和强化零件。

## 音乐包

四曲测试包（40、41、42、93）可在三版间导入。浏览器与本地安装器输出的整盘 SHA-256 逐版一致。ARMSX2 音乐室实测三版均能播放第 40 曲。

| 版本 | 三语宽屏 ISO（字节） | 加四曲测试包（字节） |
| --- | ---: | ---: |
| Original | 3,863,324,672 | 4,405,002,240 |
| The Best | 3,860,060,160 | 4,401,741,824 |
| SP | 4,459,114,496 | 5,001,877,504 |

单层 DVD 容量按 4,700,372,992 字节计。SP 原发布镜像可容纳，加此测试包后超出 301,504,512 字节。其他自选曲目的结果取决于安装后的镜像大小。

## U 盘、SD 卡与 OPL USB

FAT32 单个文件最大为 4 GiB 减 1 字节。SP 三语 ISO 约 4.46 GB，原版与 The Best 安装上述四曲包后也超过上限。使用 U 盘、SD 卡或 OPL USB 时，请按设备和加载器支持情况选择 exFAT 或 NTFS；支持 CHD 的模拟器也可以使用 CHD。使用子 CHD 时需同时保留对应的日文父 CHD，并确认每个文件都符合存储介质的大小限制。
