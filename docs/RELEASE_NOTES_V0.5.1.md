# 《超级机器人大战 Z》简体中文版 v0.5.1

v0.5.1 是 v0.5.0 之后的小版本更新，Original（初版）、The Best（廉价版）与 SP 特别盘三版同批构建。主要内容是修正画面细线、恢复按日文原文断行，以及统一一批译名。

| 版本 | 日文原盘 | 本版状态 |
| --- | --- | --- |
| Original 初版 | SLPS-25887 / 1.04 | 更新 |
| The Best 廉价版 | SLPS-73270 / 2.00 | 更新 |
| SP 特别盘 | SLPS-25920 / 1.01 | 更新 |

## 本次更新

### 画面

- **窗口细线**：在模拟器里用小数倍放大（如 1.5×、2.5×）时，地图 MAP DATA、驾驶员培养、存读档“指令”窗口等界面中间会出现 1 像素细线。放大渲染（含 4×）时，“读取”、地图指令菜单和部署菜单最后一个按钮下方还会多出一条深色线。两处均已修正，原生分辨率下画面与原来逐像素一致。感谢煮西瓜丶的反馈。
- **英文与数字**：v0.5.0 已把剧情对话里的英文和数字改为按比例宽度显示，这次补上漏掉的地图对话、滚动文字等场景；同时换了字形，字母和数字与汉字搭配更协调。
- **汉字字形**：汉字字库改为真正关闭 hinting 栅格化（v0.5.0 的关闭设置没有生效），笔画按 HarmonyOS Sans 原轮廓呈现。字号、基线与字距不变，不做逐字缩放或偏移。
- SP 特别盘四处单独显示的 COMMAND 标题改为“指令”。

### 排版

- **剧情断行**：对白换行恢复与日文原文逐行对应；审阅时定稿的断行保留。对白行也可以像日文一样以省略号开头。
- **滚动文字**：开场世界观等滚动文字按面板宽度排满每一行。
- **波浪号**：拖长音和地点字幕里的波浪号统一为“〜”，并修正若干落单的标点。

### 文本

- **译名统一**：
  - アゲハ隊／アゲハ構想 → 展翅队／展翅构想
  - ターンタイプ → Turn系机体；アプリリウス → 阿普里利乌斯（含世界地图标题）；アンダーゴレーム → 安达葛雷姆
  - コダマ隊 → 古塔玛队；因果の鎖 → 因果之链；マルチナ・レーン → 玛尔蒂娜·琳
  - 自警団 → 自警团；軍警察 → 军警；機関部按上下文译作动力舱或动力系统
  - 少数不一致的写法并入通行写法，如贝加、基姆、骷髅月联合、贤人会议、议长、警备队、时间跳跃、阿美利亚、南阿美利亚
  - SP 特别盘中继承本篇的名称同步更新。
- **社区审阅**：吸收审阅站 55 条建议，主要是第 1 话、第 13 话的断行和措辞。
- 润色标题画面待机演示里的 12 条战斗台词；剧情中的英文台词改用拉丁撇号。

### 其他

- 歌曲版 BGM 播放器（独立安装，不包含在补丁内）更新到 v5：修正战斗音效被静音、□ 快进后音乐中断等问题，可安装到 v0.5.1 的 Original／The Best 镜像。

## 选择补丁与校验

根据自己持有的**未修改日文原盘 ISO**，从 [v0.5.1 GitHub Release](https://github.com/dyzz/srwz-zh/releases/tag/v0.5.1) 下载对应的**一份** `.xdelta`。三份补丁互相独立，不能叠加在旧汉化镜像上。

| 日文原盘 | 补丁 | 原盘大小（字节） | 原盘 SHA-256 |
| --- | --- | ---: | --- |
| Original 初版，SLPS-25887 / 1.04 | `srwz-zh-v0.5.1-original.xdelta` | 3,758,358,528 | `ddbedefc0061213c50928fb213a7fb277c0345f01dab7386adc0383638a78cd2` |
| The Best 廉价版，SLPS-73270 / 2.00 | `srwz-zh-v0.5.1-best.xdelta` | 3,755,081,728 | `950e2759d0d7482387d97d6df31325d9e352097a23e0bb4724073d1538d8cf77` |
| SP 特别盘，SLPS-25920 / 1.01 | `srwz-zh-v0.5.1-sp.xdelta` | 3,791,781,888 | `c3bd8c1af4e411e5ab2ae2d4be877170b6ab1ea9b51fa62bc0b91a51ba1a2952` |

使用 xdelta3 生成中文镜像（把文件名换成自己的原盘）：

```sh
xdelta3 -d -s "original.iso" "srwz-zh-v0.5.1-original.xdelta" "srwz-zh-v0.5.1-original.iso"
xdelta3 -d -s "best.iso" "srwz-zh-v0.5.1-best.xdelta" "srwz-zh-v0.5.1-best.iso"
xdelta3 -d -s "sp.iso" "srwz-zh-v0.5.1-sp.xdelta" "srwz-zh-v0.5.1-sp.iso"
```

生成镜像的 SHA-256 应为：

| 生成镜像 | SHA-256 |
| --- | --- |
| `srwz-zh-v0.5.1-original.iso` | `c6754f75eb12be7c4b4af5c23993cfafa0d5be2bb4ecb78311029390becb3862` |
| `srwz-zh-v0.5.1-best.iso` | `90c9d05c2f9ef75a8abdfececa577fd7b0a09046045df9d1fdecc5f0ce3b0f9f` |
| `srwz-zh-v0.5.1-sp.iso` | `0175bffd0a3312db930f45d5058e56fc60058362c6941a26fb87ad8a91496ae9` |

补丁报错或哈希不符时，多半是原盘不是对应的未修改版本，请先核对上表中的原盘大小与 SHA-256。附件 `SHA256SUMS.txt` 用于校验补丁文件本身，`release-manifest.json` 记录各版原盘及还原成品的完整身份。本项目只分发补丁，不提供日文原盘或完整 ISO。

## 存档与升级

- 请先备份原盘和记忆卡存档。
- 从 v0.5.0 升级时，换用新镜像后从**普通记忆卡存档**读取进度。模拟器即时存档会保留旧版已载入的程序和文本，不适合在新版中继续使用。
- 金手指的镜像 CRC 每次发布都会变化，请使用 [金手指页](https://srwz.dreamquest.club/cheats/) 上标注 v0.5.1 的版本。
