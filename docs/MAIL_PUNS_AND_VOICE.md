# 梅尔的文字游戏、称呼与人物口吻

本文是梅尔（メール）的专项编辑决策表，记录听错、说反、错用谚语、冷笑话、文化梗及其相邻台词。每个案例都同时保留：

- 日文前后文；
- 当前受控语料中的中文译文；
- 稳定条目 ID，以及文字游戏核心行的日文前像 SHA-256；
- 梗的成立方式、当前状态和后续处理方案。

本文不是批量替换表。候选译文不等于已经写回语料或 ISO；人物名、机体名和普通术语仍以全局术语表为准。

下列“日文上下文”均从锁定的日版 `STAGE.BIN` 直接解析；“当前译文”均从当前受控中文语料按同一条目 ID 读取。说话人使用当前中文说话人表；`$n` 表示运行时玩家名。为便于人工核对，正文不以中文概述代替原句，也不把同一节中不相邻的台词拼成上下文。当前译文保留实际文字和标点，但为连续阅读合并了运行时换行；日文中的 `\n` 则原样保留，以便复核原文前像。

## 审计范围

此前源文审计共索引出 82 个 STAGE 区块中的 840 条梅尔台词。本表收录该轮源文审计识别出的全部 14 组文字游戏、误听、错用熟语及近音表达，并在口吻实例中补录 1 组《結婚しようよ》歌词引用；普通的吐槽、撒娇和剧情陈述不冒充“梗”。

附录另列 5 组已经收到反馈、但本质属于称呼、断句或语义修复的梅尔台词。后续发现新的源文证据时，应新增编号，不能静默改写既有条目。

人物口吻遵循这些约束：

- 年纪小，但不是幼稚或无能；她负责记录、联络和维修公司的账务，反应通常很快。
- 对兰德亲近、直率，会吐槽也会撒娇；不使用过分成人化、粗俗或刻意卖萌的措辞。
- 原文采用“说错—被纠正”结构时，中文也应保留这一结构。
- 无法自然复现日文音近梗时，可以改造为中文能成立的误听、误说或错用熟语，但不能只留下字面意思。
- 优先采用自然的中国大陆口语，避免机械照搬日语语序。
