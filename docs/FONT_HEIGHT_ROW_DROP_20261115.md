# 汉字高低不一：字底下移规则的副作用（2026-11-15）

交给 Codex 调查并提出修正方案。v0.5.1 发布前要定下来。

## 现象

用户 2026-11-15 看第 136 话地图对话时指出：“中文高度不一致了”，以第 3 行为例。

- 画面：迪安娜“堕天翅和Turn系机体，／还有ZEUTH……！／这场战斗是黑历史的重演吗！”
  （`story/136/dialogue/01.09/0018`，当前 Original 镜像 v0.5.0+20261115，ARMSX2 runner Metal 4×）
- 截图：[整屏](issue-assets/font-height-20261115/stage136-full-4x.png)、[对话框裁切](issue-assets/font-height-20261115/stage136-crop-4x.png)
- 4× 截图实测（2560×1792）：三行的行距一致（行底 1451 / 1564 / 1676）。第 3 行各字的字底在 1674–1677，字顶在 1600–1609，相差约 2.5 个字库行（这个场景一个字库行约 3.5 px）。所以字底是平的，字顶参差不齐，字看起来有大有小。

## 原因（初判）

2026-11-12 晚加的字库规则 `rasterizer.cjk_bottom_row_drop`（`config/fonts/zh-font-base.json`，实现在 `tools/srwz/font_rasterizer.py` 的 `apply_bottom_row_drop`，提交 `467aaaaf`）：
- 起因：用户反映汉字挨着拉丁字母时“偏上”（说、距、离），决定“全部下移”。
- 规则：最低墨迹行（灰度 ≥ 8/15）落在第 20 行的汉字，整体下移一行。结果 3,201 个汉字的字底都在第 21 行。
- 副作用：HarmonyOS Sans SC 的字形在 24×24 画布里本来是光学居中的，矮的字上下都留白（例如天 3–20、吗 3–20）。规则只看字底，把它们整体往下推，字顶也跟着下移。原来字顶分布在 1–3 行，现在是 1–4 行，矮字显得又小又往下坠。

报告那一行逐字的墨迹行（用当前配置和去掉规则的配置分别栅格化，字体 `work/font-source/harmonyos-sans-sc-1.0/HarmonyOS_Sans_SC_Regular.ttf`）：

| 行 | 字（现在，括号内为去掉规则时） |
| --- | --- |
| 1 | 堕 3–21（2–20）天 4–21（3–20）翅 3–21（2–20）和 2–21 系 3–21（2–20）机 2–21 体 2–21 |
| 2 | 还 3–21（2–20）有 1–21 |
| 3 | 这 3–21（2–20）场 3–21（2–20）战 2–21（1–20）斗 2–21 是 3–21（2–20）黑 2–21 历 4–21（3–20）史 2–21（1–20）的 2–21（1–20）重 3–21（2–20）演 2–21（1–20）吗 4–21（3–20） |

第 3 行 12 个字里 9 个被下移。

11-12 的统计（`memory: hanzi-ink-bounds-vary-by-design`）：未加规则时字底第 20 行约 1,394 字、第 21 行约 1,807 字；字顶第 1 行 994、第 2 行 1,969、第 3 行 269。

## 要你做的

1. **确认原因**：用全字库统计规则前后字顶、字底、字高、墨迹中心的分布，确认“字顶参差”是规则造成的，不是渲染或运行时的问题。顺便确认 SP 当前用的字库是否带这条规则（11-12 时 SP 字库单独锁定，没跟着改；之后是否走过 SP 的锁刷新链要查 `config/editions/sp/inputs.json` 和 `tools/special_disc/writeback/build_text_candidate.py`）。
2. **对比方案**，各出一组同场景的前后对比图：
   - A：撤掉规则，回到 v0.5.0 的字形（11-12 那个“挨着拉丁字母偏上”的问题会回来）。
   - B：按墨迹的垂直中心对齐，而不是按字底对齐。
   - C：只在字形偏上时才下移（比如墨迹中心高于全字库中位数），或者在拉丁字母一侧调基线，不动汉字。
   - 其他你觉得更好的做法。
   约束：配置里写明了禁止逐字修正，只能用全字库统一的规则；画布固定 24×24，22 px 字号不变。
3. **验收场景**：至少包括这条第 136 话地图对话、一条剧情对话（21 列）、一条中西文混排行（11-12 用过的 `THE CRUSHER说：`、`Side 3距离1.5km`，样例在 `work/review/mixed-latin-runtime-20261112/`）。用无头 ARMSX2 runner 截图（见根目录 `CLAUDE.md`，Metal 4×），每张自己打开看。
4. **交回**：结论、推荐方案、对比图路径。先别改正式配置、别提交、别重建三版；方案经用户选定后再走重建链。

## 重建链（定案后用）

改 `config/fonts/zh-font-base.json` → 更新 `config/fonts/zh-release-font.json` 里它的 sha256 → `tools/rebuild_zh_font.py --skip-fetch --refresh-manifests --refresh-asset-ratchets --force-rebuild`（不加 `--force-rebuild` 会复用栅格缓存）→ SP 字库锁刷新 → `build_editions.py --editions original,best,sp` → 全套测试（含 Unicorn 测试，0 跳过）。预渲染的 UI 贴图不走这个栅格器，不受影响。
