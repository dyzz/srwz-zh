### 现象补充

- 乱码形态为“3 个错字 + `・` + `PPアップ`”，片假名部分可辨认；
- 同屏的零件名（战技手册）、底部说明文（“装备该部件的小队员在战斗中，可和
  担任队长时一样获得 100%的经验值、PP”）显示正常，说明 Compdata/01 的
  名称与说明文（`menu/Compdata/01/0072`、`0073`，弹药筒为 `0054`、`0055`）
  回写无误；
- 受影响的只是“特殊效果”一栏的短摘要文本，与底部说明文是两组不同字符串。

### 定位结论（2026-08-14，静态证据链）

1. **码表反查**：查 `config/encoding/zh-release-font-assignments.json`，
   `秃`＝code `8C6F`、`罚`＝`8CB1`、`巅`＝`926C`，mapping 均为
   `pinned_text_table_source_glyph_reuse`（发布字库复用原日文码位）；
   这三个码位按 cp932 解码即 `経`/`験`/`値`。乱码实为未翻译的日文原文
   “経験値・ＰＰアップ”（全角Ｐ）；`・`、片假名等码位未被重新分配，
   保留原字形，因此呈现中日混合观感。弹药筒同理：`弾全回復` 中
   `弾`（`9273`）已重映射，显示为“崽全回復”。
2. **字节定位**：原盘全盘仅一处命中“経験値・ＰＰアップ”，ISO 偏移
   `0x41FBE0`，属 `SLPS_258.87`（LBA 455）文件内偏移 `0x33C3E0`——
   即乱码文本硬编码在主程序里，不在任何 Compdata 数据档案中。
3. **漏翻范围**：`SLPS_258.87` 的 `0x33C280`–`0x33C3E0` 是集市“特殊効果”
   短摘要表（16 条需译，如 `毎ターンＥＮ１０％回復`、`ＳＰ全回復`、
   `経験値・ＰＰアップ`）；紧随其后的 `0x33C400`–`0x33D6E0` 还有 28 条
   集市杂货长说明文（ブラッカリィ残骸、コンピュータコア、纳豆、化妆品等）
   同样未译（上屏位置待运行时确认）。
4. **登记缺口**：SLPS 直写翻译登记在
   `corpus/zh/menu/remaining-ui.json` 的 `slps_context_ui_by_offset`（414 条）
   与 `slps_by_offset`（205 条），两者覆盖均从 `0x33D770` 起，
   上述区间整体落在登记盲区。
5. **候选未改**：v0.2.0 候选 ISO（哈希核对一致）中该区域字节与原版完全相同。

### 修复路径与约束

- [《超级机器人大战DD》中文资料页](https://wiki.biligame.com/srwdd/%E8%BD%B0%E5%A4%A9%E9%9B%B7)
  将大魔神的该招式记为“轰天雷”；《机动战队大作战》的大魔神联动资料也采用
  [“轰天雷”](https://wiki.biligame.com/ironsaga/%E5%A4%A7%E9%AD%94%E7%A5%9E)，
  可作为既有中文本地化先例。
- 上述资料足以说明“轰天雷”不是临时意译，且比“暴烈闪电”更符合既有称呼；
  但它们不是《机战Z》官方简中术语表，所以本轮只登记为推荐定稿，不直接修改
  强制术语或下游文本。
