# 梗概、滚动字幕、图鉴统一排版核查（2026-11-06）

三类长文现在从 `config/text-layout/native-scene-contracts.json` 的同一个 `prose_policy` 导出契约，执行同一份共享 JS；不再为图鉴单独维护一套选宽策略。剧情对白、战斗台词继续使用各自规则。

## 统一规则

1. 保留原文、段落边界、段首缩进和原生空白占位行；允许重新分配普通物理换行。
2. 不保护词边界，可以在中文词内断行；标点禁则、成对省略号和完整英数紧缩作用域仍保留。
3. 按原生 glyph 宽度、step 和字形伸出计算实际占用像素；不按字符数量判断，不添加可变字距或修改字形宽高。
4. 同一页面/显示组共用一个非末行选宽目标；段落末行不参与齐宽评分，允许短。优先降低非末行宽度差，再在同样齐整的方案中优先选较宽者。
5. 最大宽度铺排不能齐整时，尝试合法断点及逐像素收窄。保留已有合法的更齐整方案，不因最少行数重新计算而退化。搜索预算至少容纳原有物理行数，并可比最大宽度的最少行数多一行；原生所有者行数上限始终优先。
6. 分字段存储的滚动字幕，按已确认的同屏分组选宽，并保持原生字段数/物理行数；不把多个字段合并成一个字符串写回。

相同规则不等于相同面板尺寸：

| 场景 | 中文 step | 最大占用宽度 |
|---|---:|---:|
| 本篇/BEST 梗概 | 16 px | 480 px |
| SP 梗概 | 16 px | 480 px |
| 本篇/BEST 滚动字幕 | 24 px | 528 px |
| 本篇两处窄条滚动字幕 | 24 px | 504 px |
| SP 滚动字幕 | 25 px | 575 px |
| 人物图鉴正文 | 21 px | 336 px |
| 机体图鉴正文 | 21 px | 546 px |
| 术语图鉴正文 | 21 px | 525 px |

英数继续使用各场景已经校准的紧缩宽、高与中文恢复值，不把所有场景强行改成一个英数 step。

## 本轮修正

- 合并配置源，梗概、滚动字幕与图鉴均使用同一选宽规则。
- 图鉴构建适配器不再先清除所有换行；让共享 JS 区分普通物理换行、缩进段落和空白分隔行。
- 排版器不在正文内部空格之前断行，避免下次格式化时把行首空格误认成新段缩进。
- 把原有合法排版纳入候选与行数预算，避免较齐整的旧排版被更不齐整的新结果覆盖。
- 对分字段的同屏滚动字幕支持固定行数约束，保留其原生显示结构。

## 全量核查与写回

共 1,711 个排版单元：梗概 131 条（本篇/BEST 共用 110、SP 21），滚动字幕 30 组（本篇/BEST 20、SP 10），图鉴正文 1,550 个（人物 820、机体 626、术语 104）。其中本篇滚动字幕覆盖 28 个源字段；“组”与“字段”并非同一计数。

全部候选通过文字、控制符顺序、段落缩进、空白占位、宽度和原生行数上限检查。

- 梗概与 SP 滚动字幕原有排版已符合本次规则，无需修改语料。
- （11-06 晚撤回：这 14 个字段超出世界史的原版固定分配，比如 `summary/09/000` 需要 44 字节、容量 38，Original 构建失败，已恢复原排版。要重排得在每个字段容量内进行。）本篇 6 组分字段滚动字幕的 14 个字段已写回 `corpus/zh/summary.json`；仅在同一显示组内重新分配换行，不增删文字、字段或显示行。写回后再次全量核查，所有梗概/滚动字幕均与统一算法输出一致。
- 图鉴通过构建阶段的同一 JS 生成排版，不把展开后的字号控制符写回作者语料。原存储行中有 28 行超出当前场景上限；统一排版后无超宽。
- 相比原存储的图鉴正文，1,424 个正文的非末行宽度差减小，125 个持平。机体 `library-text/cd2dc84ffe4d2d22` 由于原排版有一行 558px、超过 546px 面板，需要重新断行，宽度差从 15px 变为 21px；不能为了保留较小差值而保留超宽行。

保留原文、段落、标点禁则和完整紧缩作用域时，仍有不能完全等宽的条目。尤其长英文闭合作用域不能任意拆开，本轮未用补空格、改变字距或拉伸字符来伪造等宽。
