# 全角字符、英数表达式收窄与名称显示规则

2026-09-28。承接 [编码规则](VISIBLE_TEXT_ENCODING_RULES.md) 和
[首轮 LRPS2 对照](special-disc/TEXT_WIDTH_RUNTIME_20260928.md)。

## 已确定的作者规则

- 可见英文、数字最终写为原版全角双字节字形码；可见空格写为 `0x8140`。
  中文标点使用发布码表；变量、控制码保留语法。逻辑文本身份和大小写、数值、标识符不变。
- 连续英文／英数名称、纯数字和数值表达式超过 **2 个可见字符**（即至少 3 个）时，作者工具提供紧凑排版标签：
  `width:0E / space:0C`，即字形名义宽度 14 px、推进距离 12 px。
  段内单词空格和表达式符号计入长度。`MAX`、`ZAFT`、`40000`、`23:00`、`0.8`、
  `99%`、`1/10`、`1～3` 等满足条件；1～2 字符短段如 `Z`、`MS`、`1`、`20` 不自动收窄。
- 数值或型号内部的点、冒号、斜杠、连字符、正负号、百分号、范围号和乘号随完整段处理；
  ASCII 逗号仅在千位分组中纳入。中文正文的 `，。！？、“”` 等继续保持原宽和断行禁则。
  `÷` 在本轮 14 px 对照中辨识度变差，含除号的完整表达式暂不自动收窄。
- 收窄范围只包上述英数表达式段。结束时恢复该显示面的宽度和字距，再显示中文或正文标点。
  SP 普通对白和图鉴正文已验证恢复 `16/16`；本轮名称菜单已验证 `12/12`；
  SP 剧情流程长梗概正文已验证 `10/10`。
  参数均为十六进制，不能跨显示面套用。
- 闭合英数表达式段作为不可拆开的布局单元；前缀、数值、符号和恢复标签不散落到不同的行。
  若整个单元仍超过一行，返回布局错误，需重新选择可读参数或明确的作者分段。
  不删字符、不截断名称。
- 每个可见字形仍占两字节，前后四个标签增加 8 字节。显示宽度与名称槽字节容量分别检查。

`tools/srwz/renderer_metrics.py::compact_visible_runs` 实现上述作者规则；默认参数为 3、14、12。
旧入口 `compact_latin_runs` 使用同一规则。它处理无控制码的逻辑文本，为英数表达式段
生成闭合标签；已有控制码的文本需显式编辑。
可见 `%` 后先恢复 `space` 再恢复 `width`，避免拼成现有 `%<width:XX>` 格式串语法；
两种恢复顺序均由布局算法识别，百分号仍由生产编码器写为双字节字形。
名称共用文本池在生产加入标签前，还需检查全部引用、槽容量和名称复制链路。
按 3 字符门槛的候选数量和真实名称抽样对照见
[`COMPACT_LATIN_COUNT_20260928.md`](COMPACT_LATIN_COUNT_20260928.md)；
长武器名仍有列表栏目覆盖案例，默认参数不能作为全部名称的批量验收结果。
加入数字和特殊标点后的最新统计及验证见
[`COMPACT_VISIBLE_COUNT_20260928.md`](COMPACT_VISIBLE_COUNT_20260928.md)。

## 排版算法已接入

`tools/srwz/chinese_layout.py` 的测宽、保留手工断行、重新断行和布局审计现在共同考虑
`width/space` 参数：

1. 按控制码维护字形宽度和推进距离状态，换行后继续继承状态，直到显式恢复。
2. 用精确分数累加推进距离，整行求和后才向上取整到既有字格预算，避免逐字符舍入。
3. 同时检查字形右边缘。14 px 字形配 12 px 推进时，末字可能多占 2 px。
4. 保留中文标点禁则、专名保护、变量预留、续行缩进和最多行数约束。
5. 无宽度标签的文本继续使用既有字格路径。SP 作者工具和 STAGE 写入器显式传入
   本轮验证的 22 px 基准；其他 profile 可独立声明 `default_advance_px`。

SP 全部原生普通对白绑定复审：8,069 个绑定、7,853 个唯一所有者，另有 123 条战斗文本，
改动数为 0、失败数为 0。既有语料不因算法升级而被重新排出不同结果。

### 超过 21 字符的一行实测

作者工具生成标签，生产 `fit_chinese_dialogue_layout` 判断以下 33 个可见字符可放一行：

```text
“<width:0E><space:0C>ABCDEFGHIJKLMNOABCDEFGHIJKLM<width:16><space:16>中文。”
```

保守占用 446 px，预算为 `21 × 22 = 462 px`，编码含 NUL 为 75 字节。
将同一载荷放入当前 SP 的隔离对白 RAM 槽，LRPS2 实际完整显示一行，没有观察到
按 21 个字符强制换行或截断的额外限制。

## 机体名和武器名验证

### 三版最终盘存储检查

直接解压最终 ISO 的 COMPDATA，按原生机体表和武器表指针核对名称载荷。
三版加载基址分别为 Original `0x6D6800`、BEST `0x6D7000`、SP `0x764F80`，
均先与归档头的原生基址核对；不能把 Original 的基址直接套到 BEST。

| 版本 | 机体名唯一载荷 | 武器表文字唯一载荷 | 未知码／危险原始 ASCII 与空格 |
| --- | ---: | ---: | ---: |
| Original | 348 | 711 | 0 |
| BEST | 348 | 711 | 0 |
| SP | 340 | 726 | 0 |

### 当前盘自然 LRPS2 流程

- Original：冷启动加载独立测试卡，到 Z 高达的武器列表和火神炮详情。
  机体名、六条武器名、括号和相邻数值正常。
- SP：冷启动 NORMAL MISSION 1，到 Z 高达的武器列表及光束步枪详情。
  名称、中文和相邻参数正常。

### 长名称的隔离 RAM 对照

以当前 SP 为输入，为机体名提供 `Black Gale高达`，为武器名提供 `Beam Saber光束`。
新文字使用当前生产编码器，仍为全角双字节字形码；指针重定向到核对为全零的隔离 RAM。
每个变体恢复本轮同 ISO 状态。没有把实验名称写入语料、ISO 或存档。

- 仅修改 COMPDATA 表指针时，已有名称缓存使画面保持原值，不计为收窄验证。
- 同时处理本轮定位的名称缓存后，默认长名及收窄长名均实际显示。
- 收窄并恢复 `12/12` 时，机体一览、单位能力、武器列表、武器详情全部可读，
  中文尾部正常，未观察到名称与相邻栏目重叠。
- 故意使用对白的恢复值 `16/16` 时，中文尾部明显变宽，后续 PLA 图例发生视觉失真。
  这组为参数不适用的对照，不能作为通过证据。

### 原生测宽代码

SP 的 `0x13A5A0` 测宽函数也解析宽度与字距参数：`0x13A640` 读取 `width`，
`0x13A668` 读取 `space`，分别写入共享字型状态 `0x4ED5C4`、`0x4ED5C8`。
显式推进距离在 `0x13A798` 路径参与累加。测宽会修改字型状态，
恢复参数与后续消费者的显示必须一起验证。

## 图鉴与剧情流程补充

图鉴带标签正文和压缩容量回退使用 22 px；SP 流程长梗概重排与回读使用 16 px。
专名保护可以跨越宽度标签，标签不再被流程校验计为可见字符。
当前候选数量、像素对照、滚动及返回页面验证见
[`COMPACT_SURFACE_CHECK_20260928.md`](COMPACT_SURFACE_CHECK_20260928.md)。

### 正文起始状态与均匀分行

图鉴正文只要含宽度／字距标签，开头显式恢复 `<width:16><space:16>`；
起始恢复另外增加 4 字节，也需计入物理槽和压缩容量。
本轮短首行对照发现，不加起始恢复会省略首行，加恢复后两行完整显示。
不能仅依赖最后一个英数段的结束恢复来保证正文第一次绘制的状态。

图鉴、流程长梗概和纵向滚动正文先保护词语、专名、段落与中文标点禁则，
再在段内按像素尽量平衡行长；段首缩进只占第一行预算。固定短摘要、标题和横向跑马灯单独处理。
全范围清单、预览、四个待处理项及本轮 LRPS2 证据见
[`COMPACT_TEXT_ADJUSTMENT_PLAN_20260928.md`](COMPACT_TEXT_ADJUSTMENT_PLAN_20260928.md)。
