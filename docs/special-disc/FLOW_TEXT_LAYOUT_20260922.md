## 两种文本的边界

- **STAGE 流程详情长简介：21 页。** 实际显示并非 21 格 × 3 行。隔离候选的 RAM 边界探针显示，第 29、30 个全角字符仍在框内，第 31、32 个超出右边界；第 1—11 行可见，第 12、13 行不可见。因此正式换行规则保留每行 29 格的余量，最多 11 行。探针仅用于测量，最终候选复验没有 RAM 写入或即时存档恢复。
- **HSFC 短简介：39 条唯一文本、42 个实际目标槽。** 每槽含 3 个 66 字节单元，每单元最多容纳 32 个双字节字符及终止符。此处 32 × 3 是文件容量规则，不能据此描述长简介窗口。本次完成容量与 ISO 回读验证，不声称逐一完成 42 个短简介界面的运行时目视验收。
