# SP 写入编码与本篇对齐（2026-09-29）

用户授权修正 SP 剩余的旧菜单编码调用。本次工作接续 [机体与机师名称修复](NAME_OMISSIONS_AUDIT_20260929.md)。

## 原因与处理

本篇字库登记与 SP 字体 proposal 的 3,532 个主映射、54 个表面别名、36 个原文兼容映射一致。问题在写入端：`encoding_tables()` 的第二个返回值还叠加 `release-menu-codebook.json`，地形名称和武器详情使用了这个旧返回值。旧回读表也保留该映射，因此错误字节可能解码成正确中文，掩盖游戏实际取到空白或错误字形的问题。

已移除 SP 编码入口对旧菜单码表的依赖。保留四返回值接口以兼容调用方，但第二、第三项均为当前正式写入编码的独立副本。回读仅投影当前字库的主映射、表面别名和原文兼容映射。地形、武器详情及独立候选镜像入口明确选择当前正式编码。

地形写入原先按“解码文字相等”跳过，现改为逐字节比较目标编码及零填充。迁移只接受原版字节、当前目标字节或契约锁定的历史字节。武器效果仅接受锁定的旧字符串及未改变的 MIPS 操作码、寄存器；恢复受控指令后交给既有写入器，仍拒绝未知前像。

合成和最终 ISO 独立回读均核对地形、武器标签的实际编码及字形像素。武器分类标签的原生括号码 `8169/816A` 按既有括号渲染契约保留，另有独立检查。
