# SP 中文格式与对白重排检查（2026-09-28）

本轮补齐文本同步之后遗漏的格式检查。对白采用本篇／BEST 共用的
`story_dialogue` 版式（21 格、最多 3 行、续行全角缩进）和当前保词表；
不把场景标签、标题、条件、阵型名或教程固定页面套用对白版式。

## 检查与写回

以已验证 SP 当前盘的原生绑定为入口，核对 8,069 个对白绑定、7,853 个唯一语料所有者，
并检查 123 条 SP 独立战斗字幕。对白中借用的本篇记录只检查，不另写一份 SP 覆盖。
此外，扫描 SP 系统、框架、说明书／Q&A 等共 12,592 条语料的标点与数字，固定页面继续使用各自构建边界校验。
扫描唯一命中的 ASCII 标点候选为 `sd/exe/3B89E0` 的原生前缀 `(d<35:00>(d<35:00>`，
其日文原文与当前审定译文均含相同前缀，因此保留。

共写回 2,213 条：剧情 1,958 条、挑战 248 条、原生覆盖 3 条、上下文复用 2 条、战斗字幕 2 条。
以下原因有交集，不应相加：

## 动态模板例外

17 条挑战对白含 `＜ｔｍ＞…＜／ｔｍ＞` 动态数值模板。模板标签、变量名称与内容保持原样，
不按普通显示文字重排；逐条列入编辑记录的 `preserved`。
其中 8 条若直接调用普通对白重排，会在模板内部插入换行。
需要独立确定模板运行时宽度与编码契约，才能验收它们的显示版式；本轮不将它们记为已修复。
另保留 1 条来源绑定的长沉默。
