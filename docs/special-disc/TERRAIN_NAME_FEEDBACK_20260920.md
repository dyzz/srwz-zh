# 特别盘地图地形名称遗漏（2026-09-20）

用户反馈地图图例／地形信息中的「军事设施」未汉化。[原始照片](../issue-assets/special-disc-terrain-20260920/user-photo.jpg)可见「軍事施Σ」。照片未提供 ISO 身份；本地特别盘候选中复现了同一字样，因此这次修复的工程范围是特别盘，不能据此判断用户实际加载文件的哈希。

## 来源与原因

文字来自 `MAP/MAPMODEL.BIN` 的运行时地形记录。特别盘可执行文件中的成员表位于 `0x3542F0`；成员 76 的解压偏移 `0x808`、`0x824` 两处原文都是「軍事施設」，按当前运行时字表读取旧候选得到「軍事施Σ」。

本篇已有「軍事施設 → 军事设施」译文。旧的 `migrate_textures.py` 按本篇与特别盘成员匹配情况迁移资源，报告记录 66 个完整匹配的地图成员；特别盘成员 76–79 的地形记录未获得完整迁移。原文编码在中文字库下产生错误字形，不是补一张地形文字图片就能解决。

完整结构扫描发现 201 个成员中的 200 个含地形记录，共 621 条、89 种名称。旧图像组件中 132 条未读回目标译文：成员 76–79 的 12 条实际地形记录，以及成员 81–200 的 120 条「ダミー」占位名称。后者不算玩家可见地名错误。实际地形涉及川、橋、軍事施設、森、廃墟、瓦礫、渓谷、岩場、町。

## 修复

- `config/products/special-disc/terrain-name-inventory.json` 固定特别盘来源哈希、偏移表、621 条记录及语料哈希。生产构建仅使用显式清单，不重新扫描选择写入位置。
- `corpus/zh/special-disc/terrain-names.json` 复用本篇已审译文，并补桥、废墟、瓦砾、岩地、镇五种特别盘新增名称。
- `tools/special_disc/writeback/terrain_names.py` 检查原盘与当前记录前像，仅修改锁定的文字范围，保留已正确汉化的记录。压缩必须适配原成员空间，并验证解压回读；其他地图数据和已有世界地图标题保持不变。
- `build_full_text.py` 在合成现有图像资源之后写入地形；`verify_full_text.py` 从最终 ISO 逐条读取 621 条名称，并核对清单哈希。

`python3 -m unittest discover -s tests -p test_special_disc_terrain_names.py`：4 项通过，覆盖军事设施两处回读、全部记录、非文字字节保持、重复执行不变，以及旧输出／偏移表漂移拒绝。测试依赖本地特别盘原盘和字体／图像组件，无输入时明确跳过。
