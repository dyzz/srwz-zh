## 安装

本项目只分发 xdelta 补丁，不包含 ISO、存档或其他原版数据。请自行合法持有与
Redump Disc 4932 校验值一致的原版镜像，并保持文件名为
`Super Robot Taisen Z (Japan, Korea).iso`。

安装 xdelta3 后，在发布包目录执行：

```bash
xdelta3 -d \
  -s "Super Robot Taisen Z (Japan, Korea).iso" \
  "srwz-zh-v0.2.0.xdelta" \
  "srwz-zh-v0.2.0.iso"
```

不要在 v0.1.0、旧汉化版或其他修改版镜像上重复打补丁。
