## ARMSX2 runner：临时 RAM 全开

当前 runner 的 `Main.cpp` 明确设置 `EnableCheats=false`，不能仅放入 PNACH 就认为已启用。使用会话的 `poke` 命令；`Armsx2Session.cmd(...)` 可发送相同命令。

1. 使用隔离测试存档启动对应版本 ISO，运行到标题画面。确认 ELF 已加载，且尚未打开图鉴／流程菜单。
2. 用 `mem 地址 4` 读取下列四处。必须逐一匹配表中的原生指令（小端字节）；若已经是全开值，表示当前 ISO／状态已有全开。任何其它值都应停止，重新确认版本与产物。
3. 在首次进入相关菜单前写入以下命令，再用 `mem 地址 4` 回读，并实际进入四个页面验证。`poke` 参数是小端字节串，与 PNACH 的指令字表示不同。

Original：

```text
poke 00153E84 2510A200
poke 0015407C 25108200
poke 00154124 2510A200
poke 00154284 25104500
```

BEST：

```text
poke 00153E94 2510A200
poke 0015408C 25108200
poke 00154134 2510A200
poke 00154454 25104500
```

runner 当前 `poke` 只写 RAM，没有显式清理 JIT 代码缓存，因此须在首次执行这些查询前注入；若已进入过菜单，退出会话并冷启动后再做，不能仅凭 RAM 回读声称生效。加载即时存档也可能恢复其中的指令，需重新检查。

关闭：退出会话，使用已回滚全开补丁的 ISO 重新冷启动，不注入这些命令，不加载全开状态的即时存档。不要把带金手指的即时存档用作自然解锁验收起点。

## PNACH 金手指留档

以下供支持 PNACH 的模拟器本地测试使用。在该模拟器实际配置的 cheats 目录创建与本次游戏 CRC 匹配的 `.pnach` 文件，启用该游戏金手指后冷启动；CRC 以实际启动日志为准，不猜测汉化产物 CRC。运行证据需注明模拟器及金手指状态；项目运行验收仍使用 ARMSX2 runner。

Original（SLPS-25887）：

```ini
comment=Local test only - library and scenario chart
patch=1,EE,00153E84,word,00A21025
patch=1,EE,0015407C,word,00821025
patch=1,EE,00154124,word,00A21025
patch=1,EE,00154284,word,00451025
```

BEST（SLPS-73270）：

```ini
comment=Local test only - library and scenario chart

patch=1,EE,0015408C,word,00821025
patch=1,EE,00154134,word,00A21025

```

关闭金手指并冷启动才能验收原生解锁；仅删除 PNACH 不会撤销正在运行会话里的内存改动。金手指文件仅供本地测试，不加入发布包，也不重新固化进 ISO。
