# 事件字幕渲染修正：抖动、黑线与隔行感（2026-10-14）

用户在 ARMSX2（Metal、6 倍内部分辨率、反交错自动）里发现，事件鉴赏字幕会抖动并出现横向黑线；第七版（10-13）本身就有这个问题，第六版不抖但有隔行感、不够清晰。本页记录排查过程和最终做法。最终方案已由用户在 ARMSX2 确认（测试镜像 `build/iso/test/sp-test-bilinear-1x1.iso`，SHA-256 `ca6b5850…`）。

## 最终做法

| 项目 | 第六版 | 第七版 | 现行 |
| --- | --- | --- | --- |
| 字号 | 26 | 32 | 32 |
| 每句纹理 | 512×40 | 512×20 | 508×40 |
| 生成 | 4 倍渲染后缩到 40 行 | 4 倍渲染后平均缩到 20 行 | 4 倍渲染后缩到 40 行 |
| 运行时采样 | 最近点，40 行画进 20 个原生行 | 最近点，1:1 | **双线性**，40 行画进 20 个原生行 |
| 两场偏移 | 相同 | 相同 | 相同 |

- `event_gallery/subtitles.py`：`CAPTION_SCALE = (1, 1)`，`caption_geometry()` 返回每句 508×40。可见宽度从 512 收到 508，因为 GS 纹理坐标是 10.4 定点数，U 最大 1023.94：宽版试验（1016×40）中，若右边界取 1024 会溢出成 0，图元变成零宽、整句不显示。描边与阴影在纹理分辨率上用可分离的方形膨胀生成。
- 运行时（`event_gallery/runtime.S`、`event_subtitles/runtime.S`）：原生图块例程 `0x1b0f30` 生成的绘制包里 `TEX1_1 = 0`（最近点采样）。字幕包生成后，在前 16 个四字节字里找到 `TEX1_1` 的 A+D 项，置 `MMAG = MMIN = LINEAR`（`| 0x60`）。原生分辨率下，两行纹理平均成一行，相当于第七版的平均，但不会抖；6 倍渲染下是平滑放大。
- 字幕表每行的 v 偏移字，高 16 位存该特效的纹理宽度，运行时写入图元。若字幕图集超出该特效的 GS 块预算（effect 257 的反馈备份从块 `0x3D00` 起），生成器会退回 `FALLBACK_SCALE`。现行 1x1 下不会触发。

## 排查过程

1. **绘制包与场景数据重叠（真实问题，但不是这次症状的原因）。** 字幕每帧在 `0x828000` 生成 GIF 包，今天新增的场景数据（第 7 项真·超重斩的占位单位表、第 8、9 项出场数据）落进了这块地址。LRPS2 证实：字幕一出现，占位表就被改写。修复后绘制包移到私有段末尾专用的 `0x82F000`（`GALLERY_PACKET`），由 `apply.py` 的 `PACKET_BASE/PACKET_SIZE` 断言和 `verify_gallery_members` 回读双重把关；本篇字幕运行时的 `payload+0x8000` 包也加了同样的断言。证据：`work/analysis/sp-caption-packet-20261014/{current,fix}/packet-check.json`。
2. **第七版的 1:1 采样。** 修完上一项后用户仍看到抖动，而且第七版本身也有，说明问题出在渲染方法。第六版不抖（`build/iso/test/sp-test-v6.iso` 对照），区别在于它每个原生行有两行纹理。
3. **场偏移试验（已放弃）。** 实测原生绘制包的 XYOFFSET 按场奇偶在 1936.0 和 1936.5 之间交替（`0x457cf0` 为奇偶标志），字幕包始终是 1936.0。按奇偶给字幕加半行偏移后，正、反两种相位在 ARMSX2 里都出现明显条纹，已撤回，两场恢复相同偏移。探针：`work/analysis/sp-caption-packet-20261014/xyoffset_probe.py`。
4. **最近点采样造成隔行感。** 抓包（`packet_dump.py`）发现 `TEX1_1 = 0`。6 倍渲染下每个纹素被放大成硬边方块，看起来一行一行。改为双线性后，1x1 和 2x1 两档用户都确认可以，2x1 的提升不明显，因此选 1x1：显存余量大，也不需要退回窄版。

## 验证

- 单元测试全部通过（767 项，6 项按环境跳过）；`test_sp_event_gallery_textures.CaptionSamplingTests` 锁定默认几何、宽档的盒式滤波，以及两份运行时中的双线性补丁和固定偏移。
- LRPS2：脉冲高达（8 位纹理）、阿克艾里昂（最大的 4 位图集）、爆爱无限光（反馈备份）、格兰维昂（4 位）的字幕均正常显示，播放返回后状态恢复一致。截图在 `work/analysis/sp-caption-packet-20261014/` 下各子目录。
- ARMSX2：用户确认 `sp-test-bilinear-1x1.iso` 字幕不抖、无黑线、无隔行感。
