## 还原原版效果的范围

“还原原版参考”展示原盘图像，尚未把任何还原选项写入游戏。

原版第 4 页的 COMMAND `[0,96,112,120)` 与 MENU `[112,96,168,120)` 已被其他
中文取样复用。直接恢复旧绘制记录会读取现在的中文；把原英文像素写回原位置则会
同时改变当前其他消费者。

- Original／Best：COMMAND 原区域各有 8 个当前静态消费者，MENU 各有 2 个。
  涉及菜单／指令、DATA HELP、Key Help、OTHERS COMMAND 以及未命名资源。
- SP：两块原区域分别有 10、8 个当前静态消费者，逐条引用见专题的“还原范围与连带影响”。
- 未命名资源和大范围取样仍受上传上下文与运行映射限制，不能仅凭 UV 相交宣称可见损坏。

可选方向为：保持中文并重做字形和绘制效果；或还原为 COMMAND／MENU 等原版英文贴图，为完整原字块提供独立、已核实的
存储位置，保留原版几何和颜色，再检查所有引用。整页回滚会影响其他已完成的中文标签。
用户关于“可以考虑还原”的要求已纳入审阅方向，本轮未自动选择还原。页面为这四组分别提供“保留中文重做效果”和“还原原版效果”的选项；选择仅作为浏览器审阅记录，尚不执行纹理写回。
