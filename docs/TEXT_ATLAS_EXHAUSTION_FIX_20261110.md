# 文字图集耗尽时的提交修复

开场滚动正文超出动态字形图集容量时，原生文字函数提前返回而不提交已生成的文字。帧末补交这批文字时，滚动窗口的局部裁剪已复位，导致上下不可见行露出。修复把耗尽出口接到正常收尾：保持原容量与截断行为，正确提交本次文字、更新包指针并恢复调用前状态。

## 构建改动

三个当前版本共用的 `tools/srwz/typography_iso.py` 封装阶段调用 `text_atlas_exhaustion.install`。当前正式配置为 proportional；native 模式的原生对照构建不经过此阶段。

| 版本 | 指令地址 | 正常结尾 | 原指令 | 新指令 |
|---|---|---|---|---|
| Original | 0x13AA34 | 0x13ABB0 | 0260102D | 1000005E |
| Best | 0x13AA34 | 0x13ABB0 | 0260102D | 1000005E |
| SP | 0x13B4D4 | 0x13B650 | 0260102D | 1000005E |

从 ELF PT_LOAD 映射定位文件偏移；严格核对容量分支、原指令、延迟槽、正常结尾和提交调用的前像。未知版本、指令漂移和重复安装均拒绝。只替换 4 字节，不增加 ELF 大小；现有封装验证重新生成完整 ELF，并逐字节比较回读，验证 ISO 成员目录与 ELF 外的字节不变。构建回执的 `typography.verification.payload.text_atlas_exhaustion` 记录修改地址、前后字节和不扩容的边界。

## 独立分析与既有运行证据

- 原生指令级差分：三版共 72 例，对照正常终止与超限收尾，状态、返回指针和绘制包均匹配。这是组件证据，不是游戏内运行。
- ARMSX2 Original：旧场景中独立复现 96 个超限帧，区间为 4641–4646、4713–4718、4785–4790、5001–5078。内存补丁在软件渲染下消除对应窗外显示。
- 可见字符逐帧核对：4631–5100，共 470 帧、129840 个保守可见字符实例，未提交的可见字符为 0。另行在 SW 与 Metal 4× 各核对 149460 条实际提交记录，全部相符。最靠上的未提交字符在截图 y=416，裁剪底边为 y=391；图集耗尽后未处理字符最靠上的位置为 y=512。
- 上述逐帧证据限定于这段 Original 文本和该存档；不表示任意超长文本都不会漏字。裁剪边缘和小幅颜色差异存在，不宣称逐像素一致。

汇总与逐帧统计在 `docs/issue-assets/text-atlas-exhaustion-20261110/`。原始追踪及复现脚本保留在 `work/analysis/opening-overflow-review-20261110/`、`work/analysis/opening-visible-glyph-audit-20261110/`。

## 正式镜像验证

构建、测试与新镜像冷启动结果见同目录 `build-runtime.json`。静态回读、原生指令级组件测试和 ARMSX2 证据分别报告；未做 PCSX2 手动验证。

- Python 3.13 三版正式构建耗时 116.348 秒，独立 `verify_editions.py` 通过。最终三个 ISO 的 ELF 指令均直接回读为 `5e000010`。
- 全套单元测试：992 项，984 通过、8 跳过，耗时 204.796 秒。新增测试覆盖三版前像拒绝、只改一条指令、正确分支目标及独立回读发现补丁被撤销。
- 新 ISO 的 ARMSX2 Metal 4× 冷启动：未加载旧即时存档、未 poke 内存。Original 与 Best 各触发 96 次耗尽；每次立即提交 318 条记录，帧末计数为 0。检查长闪区间截图及后续节子对白，裁剪与文字正常。SP 实际进入战斗鉴赏并显示字幕；SP 未在游戏中人为制造图集耗尽。
- 本轮冻结输入包含工作区已有的另一批战斗文本校订；这些语料/config 改动不纳入本补丁提交。自动回执保留构建时的 source_head 与 input_digest，已确认本补丁源码与冻结快照逐字节相同，不把提交后的 HEAD 冒充构建来源。

本次不扩容、不修改文本、不重录视频。超限仍会停止处理后续字符串；其他文本若把截断点推入可见区，仍需另行处理容量问题。
