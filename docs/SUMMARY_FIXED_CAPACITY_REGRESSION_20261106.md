## 为什么上轮预览没有拦住

共享 JS 几何审计检查了像素宽度、段落、控制符和行数，没有检查实际编码字节容量。截图候选构建又使用可增长的归档 section 重写，能装入更长的字符串，并不等价于正式构建的固定分配写入器。正式构建原有容量限制是正确的，不能为通过这次排版而放宽。
