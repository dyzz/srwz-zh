# 图鉴、剧情流程与纵向字幕宽度验证（2026-09-28）

本次只做本地验证和候选预览。未发布、未批量写回语料、未修改 ISO。
原有控制码、变量、数值和英文全称保持原样；两个图鉴英文全称允许在词间换行。

## 1. 测量结果

| 显示面 | 版本 | 未收窄全角推进 | 可用行宽 | 临界反例 |
| --- | --- | ---: | ---: | --- |
| 人物图鉴正文 | Original / BEST / SP | 22 px | 16 字格 / 352 px | 17 字格与末行滚动箭头重叠 |
| 机体图鉴正文 | Original / BEST / SP | 22 px | 26 字格 / 572 px | 27 字格与末行滚动箭头重叠 |
| 术语弹窗正文 | Original / BEST / SP | 22 px | 25 字格 / 550 px | 26 字格进入弹窗右边框 |
| 剧情流程长梗概 | Original / BEST / SP | 16 px | 30 字格 / 480 px | 31 字格跨过右内容边界 |
| 本篇世界观滚动正文 | Original / BEST | 24 px | 22 字格 / 528 px | 23 字格及更宽行的末尾标记未显示 |
| SP 纵向叙述正文 | SP | 25 px | 建议 23 字格 / 575 px | 物理极限 24 字格 / 600 px，25 字格末尾在画面外 |

人物和机体预算包含末行箭头的保留空间，不能只按没有箭头的短文页定宽。
SP 的 23 字格是作者留白预算；24 字格才是实测物理边界。
窄距之后每行可容纳的字符数会变化，布局算法应使用像素预算，不能固定按字符串长度换行。

## 2. 实验与证据边界

使用三版当前 ISO、相应版本启动的 LRPS2 状态及复制的存储卡，在自然进入的页面中注入 RAM 标尺。
所有注入检查原文前置条件、结束符和空间容量。ISO 哈希、核心哈希与原存储卡未变化的记录见
`work/reviews/prose-maxwidth-20260928/inputs.json`。

图鉴已打开后，仅修改源数据不会改变准备好的正文缓存。这种无效果尝试不作为通过证据。
正式标尺定位完整正文的类型头与容量，修改准备后的正文缓存。
带标签正文按每行显式恢复 22 px 测量，避免默认状态或换行重置让结果偏窄。
三个版本均比较人物 16/17 字格和机体 26/27 字格的长正文末行箭头。

本篇滚动标尺不加入内联控制码，另在开始绘制之前注入复测，排除已缓存分行的干扰。
Original/BEST 的两条开场正文字体、位置参数相同；解码核对每版全部 28 条的字体均为 24 px，但其他记录位置不同。
因此，本次运行结论限定为世界观滚动正文选样，不以相同字体自动推定所有其他位置的画框。
BEST 表位置采用 `config/editions/best/source-layout.json` 的已审计映射读取，并检查原位置、偏移单调性与归档尾边界。

SP 在实际剧情序章验证第一条叙述字幕。静态核对全部 10 条，25 px 字体与位置参数一致；
运行边界仍属选样证据。奖励菜单中未进入剧情的旧状态不计入有效字幕证据。

运行选样验证的是行宽边界。整批写回后的字节容量、共享引用、分页、滚动速度、停留时序及
PCSX2／人工验收尚未完成，不把 RAM 标尺等同于最终中文语料验收。

## 3. 对排版算法的约束

- 图鉴保留人物 16、机体 26 字格，术语本地候选预算扩至 25 字格。
- 流程本地候选扩至 30 字格；本篇世界观滚动正文保留 22，SP 叙述按 23 字格、25 px 计算。
- 段落缩进、空白分隔行保持；均衡目标计入首行缩进后的总占用宽度。
- 词语、专名和中文标点禁则先满足，再尽量让同段各行长度接近；使用最少可行行数。
- FAITH、PLANT 的完整英文全称在词间闭合并重开窄距范围，保留全部字母、大小写和空格。
  普通英文缩写、型号和数值表达式继续保持完整。
- 补充候选中实际被拆开的“结合性技术”“特权阶级”“超级机器人”“反地球联邦组织”断行保护。
- 可见字符仍按全角双字节字形编码。内联标签只控制字形宽度与推进，不改变数值或名称。
- 叙述与世界观滚动流本轮不加入窄距标签，避免未经验证的两字节流控制语义。
- 原有控制码、变量不重写、不对语法本身加标签；控制序列保持不变作为重排检查条件。

## 4. 更正两篇滚动字幕的行数预算

原预览把当前中文稿行数误作原盘上限：`summary/00/000` 的 34、`summary/01/000` 的 16。
重新解析原盘 MTV_PROS 并匹配源文本哈希后，原盘分别为 **46、24 行**。
均衡候选为 **35、17 行**，位于原盘行数范围内。这个更正解决静态行数阻塞，不证明滚动时序已验收。
