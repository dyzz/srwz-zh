## 场景与资源的边界

effect资源相同不等于当前鉴赏已完整复刻原关卡：关卡脚本还会控制地图物件、单位、镜头、BGM及调用前状态。当前鉴赏已为脉冲等条目移植部分原始舞台指令，部分锚点或初始镜头仍使用明确记录的独立场景配置。不能将画面构图差异一概归因于SP原资源不同。

原始比较未包含The Best；2026-10-13补充复核确认13个effect中12个连压缩数据都相同，阿克艾里昂只差第710帧语音编号的一字节。两版本篇38段音频中，巨神Σ“充能”一段的编码/长度不同，另外37段逐字节相同；不据字节差异推断台词改变。此处是静态资源与原音核对，不替代原关卡与鉴赏的逐段实机画面对照。
