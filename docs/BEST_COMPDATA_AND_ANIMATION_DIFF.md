# Original / The Best：COMPDATA 与战斗动画差异解析

2026-09-05。比较对象是两张原生日文 ISO 的数据，不是汉化后文本差分。本报告补充此前未解明的四处 COMPDATA 数据，以及 13 个 TWP 块的武器归属、动作结构和具体修改。

**结论：COMPDATA 的四处额外字节是姓名拼接格式和图鉴关联数据订正；TWP 的 13 处归档块变化全部属于命运、传说、强袭自由、无限正义高达。动画修改包含调色参数、动作帧记录、缩放／位置及绘制部件数据，不能把 BEST 的可见变化缩减为文本和 B-Save。**

这里的“帧”指归档内可独立寻址的帧记录。它可能包含控制记录、初始化记录或复用关系；不将记录数等同于播放帧数或动画秒数。序列、帧、机体和武器编号均从 0 起算。

## 1. COMPDATA：全部差异归类

两版解压长度都是 524,032 字节，原始解压数据有 10,036 个字节不同。脚本对所有不同字节分类，没有留下未归类差异：

- 9,548 个对齐的地址字发生 `+0x800` 重定位，对应加载基址 `0x6D6800 → 0x6D7000`。
- 内嵌代码区 `0x80–0x8BF` 有 57 个指令字不同：33 条地址立即数调整，24 条跳转／调用目标调整。内部目标按 `+0x800` 校验，外部目标按主程序函数匹配表校验；没有新增或删除指令，也没有发现本模块内部的新条件分支。外部被调用函数本身的变化仍应参见程序差异报告。
- 其余 209 个不同字节全部属于下列四处数据订正和四处文本记录改动。
- 2,960 条武器记录在名字指针重定位归一后逐字节相同；807 台有效机体的武器槽表也相同。因此，未改动这两张表中的攻击力、弹数、EN、射程、属性或武器配置。

[完整机器证据与断言结果](../work/analysis/compdata-twp-best-20260905/findings.json)；[可复跑的比较脚本](../work/analysis/compdata-twp-best-20260905/build_findings.py)。

### 姓名格式的程序依据

主程序 `FUN_0035F130` 读取驾驶员记录 `+0x45`，并选择以下格式：

```c
if (pilot.name_format == 0) {
    if (given_is_empty || family_is_empty)
        sprintf(out, "%s%s", given, family);
    else
        sprintf(out, "%s・%s", given, family);
} else {
    sprintf(out, "%s%s", family, given);
}
```

亨利的两个字段一直分别为 `family=スタイガー`、`given=ヘンリー`，BEST 改的是上述开关。日文姓名的姓在前分支没有变化。

### 同包文本差异，保留原先结论

- 驾驶员 796、797 的 given 字段：`ティターンズ → エゥーゴ兵`，两条各有 10 个字节不同。
- フォトンマット（強）的说明：`ダメージを２０００軽減する → ２０００以下のダメージを無効化する`，即“减伤 2000”订正为“无效化 2000 以下伤害”。
- バリア・フィールド的说明：EN 消耗 `１０ → ５`。

这些说明改动没有对应到本次 COMPDATA 武器数值表的变化，不能据说明反推 BEST 改了屏障算法。此前其他文件中的 Q&A、技能说明和剧情订正不重复计算在此包内。

## 3. 动画内部结构与具体数值

13 块均可按下列层级严格切分，所有动作和帧边界都通过长度断言：

```text
TWP.SEG 的块偏移 → 解压 TWP 块
  容器头 + 子段偏移表
  section 0：16 字节参数头
  section 1：动作选择表 → 子动作映射 → 动作偏移表 → 帧偏移表 → 帧载荷
  section 2：TIM2 纹理包
  section 3：TIM2 纹理包
  可选尾部资源
```

两版的动作选择表和子动作映射一致。**两组 TIM2 纹理包在全部 13 块中逐字节一致**，有尾部资源的块 859，其尾部也一致。因此不能称这些变化为重绘贴图或替换纹理；修改落在参数与动作数据。

### 缩放与位置：块 859 的独立修改

`ドラグーン・フルバースト` 的差异不属于上表的主要调色模式：

- 若干更新项由掩码 `0x08` 改为 `0x09`，新增双轴变换值 `0x10001000`、`0x09990999`、`0x0B330B33`。
- 按此格式常见的 12 位小数缩放表示，分别为双轴约 `1.0`、`0.60`、`0.70`。原记录未显式写入该字段，不能把原值直接说成 0 或 1。
- 一组位置字 `0xFF60FFF8 → 0xFF68FFF8`；按两个有符号 16 位数读取为 `(-8,-160) → (-8,-152)`。
- 增加一条带 `0x0B330B33` 的部件更新项。

这支持“修改部件变换／位置”的结论；具体对应哪个龙骑兵、哪一束光和屏幕方向还没有播放证据。

### 帧记录与绘制控制

- 块 846：序列 1 为 86 → 88，序列 2 为 74 → 77，序列 3–12 各增加 1 条，共 +15。
- 块 857：序列 1–12 从 `[133,74,34,69,134,83,79,80,133,75,35,70]` 改为 `[134,76,35,71,135,85,81,82,134,76,36,71]`，共 +17。
- 块 861：记录数不变，修改集中在序列 1。存在部件项删除／插入和控制值变化，不能仅凭差分命名为“修复闪烁”“修复遮挡”或“修复镜头”。
- 包头 `0x44`：838/846/847/848/857/863 为 `03 → 01`，839/843/856/865 为 `00 → 01`；840/859/861 不变。**839 只有这一字节不同，其效果仍未定名**。同位置在不同块中反复修改，不足以证明它一定是混合、反转或命中特效开关。

## 4. 对当前 Original 汉化版的迁移决定

1. **COMPDATA 可以按字段回迁这四处订正。** 亨利的姓名拼接和ゴッドグラヴィオン的分类／图鉴映射值得保留。エリファス的字段订正也可同步，保持主记录和查找表一致。这里只改原位数据，不引入 BEST 图鉴解锁条件；现有全开放补丁继续沿用。
2. **按用户后续决定，战斗动画排除，不回迁。** 上述 TWP 解析仅保留作差异证据，不列为当前待办或发布条件。
3. 作为历史分析边界：整个 BEST TWP.BIN 不能直接覆盖进 Original 固定布局。原槽容量 424,556,544 字节；BEST TWP 为 424,559,024 字节，超出原槽 2,480 字节。本轮不修改该资源或其布局。
4. 四字段的运行验收应检查亨利姓名全名、机体图鉴关联和作品分类，同时确认全开放行为。

本报告最初仅产出分析、解析脚本和证据。四字段的后续回迁实现、构建状态和完整项目处置见 [BEST 回迁清单](BEST_BACKPORT_CHECKLIST.md)。动画未改写，也未执行 PCSX2 播放验收。
