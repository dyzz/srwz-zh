## 后续排版的执行方式

1. 先确定资源／面板／调用者与原生基准；保留所有可见英文、数字和标识符。
2. 共享完整控制分类及预算；tm、@和数值方括号不送入静态重排；未知控制语法拒绝。
3. 图鉴通过生产字号编译器生成闭合作用域，再按profile重排；预览用同一条路径，不能将生成height标签反写作者语料。
4. 只将检查通过的物理断行写回明确的作者字段；保留原生控制、缩进、空白占位、槽容量与行数。预览中的“相对历史布局有变化”与“不同于当前源译文”分别记录。
5. 改动后运行控制合同／对白／占位行检查、必要测试、三版构建回读，再做目标LRPS2运行对照。
6. 动态展开精确宽度、完整协议消费者、全部符号光学矩阵和原生measure修复继续单独跟踪。共享分类／预算已实现，但不是完整统一IR，也不是完整反编译完成声明。
