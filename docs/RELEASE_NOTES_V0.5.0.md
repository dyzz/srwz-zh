# 《超级机器人大战 Z》简体中文版 v0.5.0

v0.5.0 首次正式加入 **SP 特别盘**汉化，同时更新本篇 **Original（初版）** 与 **The Best（廉价版）**。三版同批构建，译名、战斗台词和排版规则保持一致，并全部内置战斗动画方块快进。

| 版本 | 日文原盘 | 本版状态 |
| --- | --- | --- |
| Original 初版 | SLPS-25887 / 1.04 | 更新 |
| The Best 廉价版 | SLPS-73270 / 2.00 | 更新 |
| SP 特别盘 | SLPS-25920 / 1.01 | **首次发布** |

## 本次更新

### SP 特别盘（首次发布）

- **中文化范围**：剧情模式的对白与梗概；挑战模式（三种难度各 6 关）的简报、胜败条件与对白；特别剧场；战斗鉴赏；资料库（图鉴、Q&A、教程）；中断存档提示及各类系统菜单。
- **新增「名场面集」**：位于“特别剧场”，收录本篇 22 段出击、合体与觉醒演出，按原作事件录像顺序排列，例如脉冲高达出击、格兰维昂合神、创圣合体·阿克艾里昂、BIG-O·Showtime、真·超重斩、镇魂曲发射、双卫星加农炮发射和新创世纪发射。
  - 在列表中按 **○** 只看演出，按 **△** 连同地图对白与语音一起观看，播放中按 **×** 返回列表。
  - 每段按原关卡还原登场机体、驾驶员与 BGM，演出结束后回到原页码和选中项。
- **战斗鉴赏**：设置中新增关闭 BGM 的选项，关闭后仍保留语音与音效。机体、驾驶员、武器名称与本篇译名同步，修正驾驶员查看提示的按键图标及说明中的动态名字。
- 图鉴、Q&A 与人物／机体名称沿用本篇已审定译名，特别盘新增条目单独翻译。
- 标题画面、按钮及特别剧场横幅等图片已重绘为中文。

### 本篇 Original／The Best

- **事件演出字幕**：部分关卡事件演出（如 Pilder On!、真·超重斩、天使剑全名）补上中文字幕，喊招与招式名分开显示。
- **开场滚动文字与剧情梗概**：重新修订兰德线开场、宇宙世纪开场和世界历史滚动文字，以及剧情流程中的梗概。正文统一按原版版面宽度换行，不再长短不一。
- **滚动文字闪行修复**：修复开场世界观等长篇滚动文字整块短暂消失或闪烁的问题。
- **图鉴与梗概恢复原版进度解锁**：v0.4.2 及更早版本默认全部开放关键词、人物、机体和剧情流程，本版恢复为随游戏进度解锁。需要全开的玩家可单独启用两组金手指（图鉴全开、梗概全开），地址与用法见 [金手指说明](LIBRARY_UNLOCK_TEST_CHEATS_20261106.md)。
- **标题画面右下角显示版本号**，反馈问题时可据此确认所用版本。
- 开场路线选择、战斗 SELECT 标题、OTHERS COMMAND 等界面贴图完成中文化。修订 8 个关卡标题，如第 95 话改为“魂之凯歌”。

### 三版共通

- **译文审校**：在授权参考尼禄卡奥斯汉化实况译文的基础上，逐条对照日文原文校对和润色剧情对白。吸收社区审阅站多轮确认的改稿建议。同一说话人在同一场景中的重复台词统一为一种译法。
- **战斗台词**：同步经审阅的战斗台词与喊招，修正三处战斗台词触发条件，使对应台词在正确场合出现。
- **术语与译名**：一次性统一 204 处术语写法。Original、The Best 与 SP 的人名、机体名和武器名保持一致，例如格兰维昂相关名称、阿克艾里昂、魅影（シルエット）。
- **排版**：
  - 剧情中的英文与数字改为按比例宽度显示。
  - 战术地图对话框按实际可见宽度排版，避免文字被遮挡。
  - 剧情续行统一缩进，换行避免拆开人名和固定词组。
  - 剧情中零星未着色的人名已补上颜色，地点字幕居中并统一标点。
- **界面修复**：
  - 驾驶员培养、武器选择等界面边框的拼接黑线（[#32](https://github.com/dyzz/srwz-zh/issues/32)）。
  - 战斗特效中文文字透底、毛刺与光晕风格异常（[#30](https://github.com/dyzz/srwz-zh/issues/30)）。
  - 小队名 THE HEAT 乱码及 The Best 截断（[#31](https://github.com/dyzz/srwz-zh/issues/31)）。
  - 图鉴 ROBOTS SPECIFICATIONS 标题字母贴图损坏。
  - 集市滚动宣传语漏译。
  - 钢狮子电锯演出的贴图溢边。
- **方块快进内置**：三版均内置类似《破界篇》的战斗动画快进。战斗动画中**按住方块键（□）**，可跳到演出的下一个阶段；不按时与原版相同。本版不再单独提供不带快进的补丁。

## 选择补丁与校验

根据自己持有的**未修改日文原盘 ISO**，从 [v0.5.0 GitHub Release](https://github.com/dyzz/srwz-zh/releases/tag/v0.5.0) 下载对应的**一份** `.xdelta`。三份补丁互相独立：SP 补丁只能用于 SP 特别盘，本篇补丁不能叠加在旧汉化镜像上。

| 日文原盘 | 补丁 | 原盘大小（字节） | 原盘 SHA-256 |
| --- | --- | ---: | --- |
| Original 初版，SLPS-25887 / 1.04 | `srwz-zh-v0.5.0-original.xdelta` | 3,758,358,528 | `ddbedefc0061213c50928fb213a7fb277c0345f01dab7386adc0383638a78cd2` |
| The Best 廉价版，SLPS-73270 / 2.00 | `srwz-zh-v0.5.0-best.xdelta` | 3,755,081,728 | `950e2759d0d7482387d97d6df31325d9e352097a23e0bb4724073d1538d8cf77` |
| SP 特别盘，SLPS-25920 / 1.01 | `srwz-zh-v0.5.0-sp.xdelta` | 3,791,781,888 | `c3bd8c1af4e411e5ab2ae2d4be877170b6ab1ea9b51fa62bc0b91a51ba1a2952` |

使用 xdelta3 生成中文镜像（把文件名换成自己的原盘）：

```sh
xdelta3 -d -s "original.iso" "srwz-zh-v0.5.0-original.xdelta" "srwz-zh-v0.5.0-original.iso"
xdelta3 -d -s "best.iso" "srwz-zh-v0.5.0-best.xdelta" "srwz-zh-v0.5.0-best.iso"
xdelta3 -d -s "sp.iso" "srwz-zh-v0.5.0-sp.xdelta" "srwz-zh-v0.5.0-sp.iso"
```

生成镜像的 SHA-256 应为：

| 生成镜像 | SHA-256 |
| --- | --- |
| `srwz-zh-v0.5.0-original.iso` | `2a76a11f84bb9d0b75363fce528e4f5e319d102597d11f807b1a07644bfc7749` |
| `srwz-zh-v0.5.0-best.iso` | `6f0df648c20e495e776c769ebe862af7918a2ae9f00a50775049bca8756318fc` |
| `srwz-zh-v0.5.0-sp.iso` | `e09afe50f0131691456489e300ba089aef8e768f0c2ffb9dd018b91b725e1c37` |

补丁报错或哈希不符时，多半是原盘不是对应的未修改版本，请先核对上表中的原盘大小与 SHA-256。附件 `SHA256SUMS.txt` 用于校验补丁文件本身，`release-manifest.json` 记录各版原盘及还原成品的完整身份。本项目只分发补丁，不提供日文原盘或完整 ISO。

## 存档与升级

- 请先备份原盘和记忆卡存档。
- 从旧版汉化升级时，换用新镜像后从**普通记忆卡存档**读取进度。模拟器即时存档会保留旧版已载入的程序和文本，不适合在新版中继续使用，也不能用来判断修复效果。
- 依赖 Original（初版）金手指的玩家请继续选择 Original 补丁。The Best 的程序地址不同，初版金手指不能直接套用。

## 验证范围

- 三份补丁均从各自的日文原盘实际还原，并核对成品大小与整盘 SHA-256。全套 1,043 项单元测试通过。
- 使用 ARMSX2 冷启动三份成品镜像抽查。Original 与 The Best 分别用空白记忆卡和已有进度的记忆卡进入资料库，核对图鉴、梗概和剧情流程的原版解锁。SP 进入战斗鉴赏并播放战斗。
- 全路线通关、真机和 PCSX2 手动验收不在本轮范围内。遇到问题欢迎反馈。
- 详细记录见 [构建与验证记录](RELEASE_BUILD_V0.5.0.md)。
