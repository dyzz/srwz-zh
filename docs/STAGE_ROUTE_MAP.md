# SRWZ 章节顺序与路线图

本表把游戏内 `COMPDATA.BN` 的 `Stage Name` 文本按实际游玩顺序整理。
标题以本地 clean-room 解析结果
`work/parsed/srwz-data.json` 为准；表内方括号数字是 `Stage Name`
段落中的 `ordinal`，**不是** `story/NNN` 文件号。

中文标题来自 `corpus/zh/menu/stage-names.json`，每格同时保留日文原题，供人工
逐项校对。女主人公第 1～5 话已经定稿并纳入整合写回；其余标题仍是尚未写回的
`draft` 候选。

当前能够确认的是“章节标题与路线顺序”。一个章节可能使用多个 story
资源文件，因此本表不表示标题已经与 `story/NNN` 建立了一对一映射。

主流程概览：

`选择主人公 → 1–9 → 共通 10–15 → 太平洋/加利亚大陆 16–19 → 共通 20 → 主人公路线 21 → 共通 22–25 → 主人公路线 26–32 → 二选一路线 33–35 → 主人公路线 36–40 → 共通 41–46 → 主人公路线 47 → 通常/隐藏路线 48–53 → 共通 54–55 → 通常/隐藏路线 56–57 → 共通 58 → 主人公路线 59 → 最终分支 60`

## 核对边界

- 本地解析得到 122 个 `Stage Name` 条目。
- ordinal 0–106 共 107 个标题，全部已在上面的路线表中覆盖；共通章节会在并排路线栏中重复显示。
- ordinal 107–121 共 15 项，全部列在“非章节标题项”中。
- 中文标题是 v1 `draft`，术语表和 review TSV 会继续暴露待确认的作品专名；
  本路线表不把首译状态提升为 `reviewed`。
- 公开路线资料仅用于确定话数、分支和汇合关系；标题字形与标点使用本地游戏数据。例如本地数据为“闇の住処”“粛清の嵐”“塗り潰される明日”。
