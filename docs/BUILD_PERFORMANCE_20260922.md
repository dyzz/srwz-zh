# 构建耗时回退复核与修复（2026-09-22）

上一轮把 374.181 秒的三版完整重建当作日常构建时间，口径不正确。统一入口固定使用强制全量，没有接回之前的按组件增量；SP 还有始终最大压缩及重复验收的成本。本轮修复入口与失效传播，并分别测试完整构建、无变化复用和单条文本更新。

## 实测结果

| 场景 | 耗时 | 口径 |
| --- | ---: | --- |
| 三版完整构建，修复前 | 374.181 秒 | 上一轮同一文本快照 |
| 三版完整构建，SP 压缩与重复回读修复后 | 239.325 秒 | 仍重建三版，约减少 36% |
| 相同输入重跑三版 | 15.160 秒 | 三版均为 verified_current_reuse，仍核对实际 ISO/日常副本/回执 |
| Original 单条对白更新，最终修复后 | 61.558 秒 | 含私有工作区、封盘、独立内容回读、日常副本发布 |
| 其中组件阶段 | 19.050 秒 | 只重建 DATA/STAGE.BIN；包含原盘证明刷新等准备 |

首次三版复测在修复 SP 压缩及重复回读后进行；后续单条文本复测加入了字体快照引用与 LIBRARY 偏移表的失效判断修复。表内是各场景的独立实测，不把不同运行的最小阶段时间拼成总耗时。使用已有本地资源与工具链，不代表空缓存冷启动。

SP 整版由 237.533 秒降至 98.268 秒。原先系统文本的单独 profile 共 77.307 秒，其中 36 次最大压缩占 75.432 秒；快速压缩加空间不足回退后，系统文本写入为 17.335 秒。

| --- | ---: |
| codec | 0.117 |
| components | 19.050 |
| fonts | 0.091 |
| iso | 10.259 |
| iso-toolchain | 4.995 |
| readback | 17.202 |
| 日常副本复制、哈希与 skip 验证 | 1.572 |

整批还包括输入冻结、缓存复制、原盘与当前盘哈希、回执绑定等开销。**61.558 秒不是旧文档中约 13 秒的同口径测试**：旧日常入口不包含这条统一入口的全部私有工作区准备与独立最终内容回读。本轮保留这些验证；当前封盘约 10.3 秒、独立回读约 17.2 秒、工具链准备约 5 秒，仍是固定成本。

## 修复内容

1. 取消日常入口固定强制全量；相同输入只有在快照、实际镜像、日常副本与回执绑定均通过后才复用。`--force-rebuild` 保留完整重算入口，旧版严格等价检查不会被复用绕过。
2. Original 仅语料变化时，从同工具／配置／字体／基线的上一批次复制独立可写缓存。旧生成配置先校验哈希；封盘后刷新的 ISO 输出锁不当作组件损坏；重访已有输入工作区时刷新其缓存，避免混入旧组件。
3. 私有工作区显式使用冻结清单，配置查询及源码身份不再误读父目录 Git。
4. 全量与增量的字体快照引用统一保留 snapshot_id，避免纯回执格式差异触发 SLPS/VT1 重建。
5. LIBRARY 回执的字体覆盖信息变动不再直接触发 SLPS/MTV_PROS 重建。先验证完整偏移表契约，再比较实际写入范围、字节摘要和归档大小；真正重排偏移仍会使缓存失效。兼容源配置的包含末字节边界与回读报告的排他边界。
6. SP 可变文本块先用 rust-fit；原定空间不足才回退 rust-maximum。维持尺寸、完整解压回读与固定 LBA 约束；冻结图像继续使用原有压缩字节契约。
7. SP 封盘发布前已经独立回读，外层保留回执/成员/ISO 绑定校验，取消再次运行同一完整验收脚本。

## 验证与边界

- 冻结快照上的 106 项相关测试通过，覆盖缓存命中、破损回执、工具/配置失效、强制重建、私有输入清单、偏移表变化、槽位回退及 SP 字体别名/文本写入。测试后来仅按提交边界拆分文件，拆分后的模块再次通过。
- 三版完整结果与最终 Original 单条更新分别经过 verify_editions 独立绑定校验。
- Original、BEST 的完整构建 ISO 与优化前逐字节一致。
- SP 只有 STAGE、COMPDATA、NISVDATA 的压缩字节不同；对全部改变的块逐个解压比对，内容一致，NISV 非目标范围及其他输出成员均相同。
- 单条对白修改和恢复均仅在 benchmark 目录进行。增量修改结果与强制全量 ISO 哈希一致；最终恢复后的 ISO 回到上一轮完整基线 f3a36c90bad5a4e303ecd4e44b84563ad460909716100fb8fbbe7bf8a4021ced。最终日志只列出 DATA/STAGE.BIN。
- 当前工作树同期有新的术语、Q&A、剧情编辑。首次直接在当前工作树运行旧 Q&A 基线用例遇到 page 17 的共享文本差异；性能及内容对比改用上一轮已验证的同一冻结语料。当前工作树的新文本不属于本轮语义验收。
- 用户工作区的当前三版 ISO、日常镜像与文本保持原状态；性能候选位于 build/benchmarks/ 下。审阅站无更新；无模拟器运行验收。
- 目前语料变化后的 SP 仍为完整 SP 构建，未声称已实现其逐组件增量。构建工具或冻结依赖变化后的首次运行会保守全量重建，15.160 秒仅适用于相同输入复跑。
