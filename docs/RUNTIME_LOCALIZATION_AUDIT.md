  310a2c5bebcc0be343f5865176dec994f6951c6efbb576dee9af125ef4dcba88

第一至第五话标题、STAGE 001～005 剧情、全部 348 个机体显示名、全部
711 个武器名和五张 atlas suite。上一份采用旧
22pt CJK 基线的 `b608…` 镜像已经通过“确认人物→加载第 1 话”，连续运行
243 秒且日志零 TLB Miss；第一关胜败条件、系统设置、队长效果搜索和特殊技能
搜索各有一张哈希锁定截图。后续 `c2ba…` 镜像还通过了 8 秒 fresh-process
DVD／ELF／PINE Running／0 TLB 启动门。当前 `310a…` 镜像对 1,754 个最终
CJK assignment 做逐字选型，将“尔”提升到 25pt，并把开场简介的“凉／缺”
纳入字库需求闭包；静态与零 LBA shift 已通过，但尚未运行。人物确认后转场和
逐屏视觉证据必须重新绑定，不能沿用旧镜像的画面结论。

## 4. 建议的后续顺序

1. **先复测当前 `310a…`，再补齐 P10 数据库视觉矩阵。**
   `b608…` 已证明进入第一关，并对驾驶员技能和队长效果取得局部截图；当前
   ISO 改为逐字形光学选型，并加入男女主人公简介、全部机体名和全部武器名。先确认转场、
   新字形和零 TLB，再用第一幕间原生存档完成机体特殊能力、精神指令以及前四个
   家族的完整列表／详情验收，再用早中晚期存档核对第五个全武器家族。

2. **审校全武器与全机体译名。**
   写回范围已经完整，但全部武器仍处于 draft、机体语料也含 draft／reviewed
   混合状态；继续避免把片假名专名机械直译，并把争议项逐个升级为人工确认。

3. **完成系统设置、敌军列表和信息页细项。**
   合并 P4～P9 已有 embedded UI 分层，逐页验证列头、选项、帮助和状态色。

4. **统一关卡标题与开场人物资料。**
   同一个标题必须覆盖标题卡、作战目标、战况报告及其他重复 surface。

5. **最后单独处理图片／未定位渲染资源。**
   包括世界地图地点标题及五张 atlas 的运行时映射，不与普通文本写回混为一项。

## 5. 验收原则

- “已有中文语料”不等于“当前 ISO 已显示中文”。
- “静态候选通过”不等于“同一 PCSX2 页面已验收”。
- 人物、机体和武器专名优先采用官方中文译名；没有共识时登记来源并人工确认。
- 每次只增加一个可归因分层，保持单一 ISO、固定哈希、零意外 LBA 偏移和
  fresh-process boot 证据。
