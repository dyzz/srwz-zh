## 日文原版的姓名显示差异

日文普通版成功读取了进度，但存档内的部分中文姓名显示为异字。例如汉化界面的「节子」在日文原版显示为「範子」。本项目码表把 `94CD` 分配给「节」，该码位在原始 CP932 / 日文字库对应「範」。

本次主存档前 160 字节在 Best 保存前后完全相同，姓名字节仍为 `94 CD 8E 71`。因此这个显示差异来自两套字库对既有姓名字节的解释，不是 Best 重新保存引入的姓名内容变化。进度可读取不等于跨语言字形完全相同。
